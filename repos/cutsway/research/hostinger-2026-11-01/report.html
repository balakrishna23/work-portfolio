1. Domain findings and proof

The live Hostinger result for custway.com explicitly reported that the domain is already taken. This does not establish its owner, whether you already own it, or whether it is for sale. A hosting purchase cannot make an already registered domain available. If it is yours, it can be connected; otherwise an owner sale would be a separate transaction at an unknown price.

The cutsway.com search offered the exact match for registration. This is a point-in-time availability result, not a reservation or completed registration.

The ₹1 offer is not a ₹1 total purchase. I opened the domain cart and verified the three-year subtotal: ₹2,999 before taxes and fees, made up of ₹1 for year one and ₹1,499 for each of years two and three. It renews at the currently listed ₹1,499/year. The research item was removed afterward and the cart showed empty.

Hostinger’s domain table lists standard .com first-year and renewal pricing at ₹1,499/year and the conditional three-year promotion. Free WHOIS privacy is included on supported extensions. A qualifying annual Premium/Unlimited/cloud purchase offers an eligible domain free for one year; .com is on the eligible list. Claim the free domain with hosting rather than paying for it separately first. This benefit cannot acquire custway.com from its existing owner.

Source checks: eligible extensions and claim conditions. Single and monthly hosting do not qualify. Some help articles still say “Business,” while the current India sales page calls the tier “Unlimited”; the live sales card explicitly includes a one-year domain. Current KVM free-domain offers cover selected other extensions, not .com.

2. What this project actually needs

I inspected launch/README.md, launch/rawpile/index.html, its shared scripts and settings, robots.txt and sitemap.xml. The ready-to-upload Rawpile folder contains 27 files totaling 4,056,892 bytes (approximately 4.06 MB; rechecked against the current revision). External libraries and fonts add network requests beyond that local folder size. The project is HTML/CSS/JavaScript, uses three.js in the browser, and has no required Node.js server, PHP application, database or build step. Booking currently falls back to email.

Therefore any normal static-file web hosting is sufficient for its present architecture. This is an engineering assessment, not a production load test. More server RAM or PHP workers will not directly improve browser rendering of the 3D scene. CDN coverage and asset delivery can improve loading; device GPU, browser, JavaScript and image complexity affect animation smoothness.

Use Hostinger’s Custom PHP/HTML website option and upload the contents of launch/rawpile into the domain’s document root. Preserve its folder structure. Do not rebuild this finished site in WordPress or the website builder merely to host it. Official custom-site setup instructions.

9. Ongoing costs and practical choice

Premium annual: ₹2,388 before tax for the first year, with an eligible available .com included for that year. If 18% GST applies, the illustrative total is ₹2,817.84; this is arithmetic, not a verified tax-inclusive checkout quote. Keep the actual tax line from checkout as authoritative.

Premium four-year: ₹6,672 hosting before tax; domain years two through four add ₹4,497 at today’s ₹1,499/year renewal price. Four-year subtotal is therefore ₹11,169 before tax and paid email, assuming unchanged domain prices. With the displayed coupon, that subtotal would be ₹10,168.20. Future renewal prices can change.

Premium currently offers 2 mailboxes/site free for one year, with 1 GB each. Live tooltips list renewal at ₹39/mo per mailbox on a 12-month term; Unlimited’s year-one unlimited mailboxes also become paid per mailbox. One mailbox therefore adds ₹468/year before tax at that listed rate. For an illustrative second year on annual Premium: ₹5,388 hosting + ₹1,499 domain + ₹468 for one mailbox = ₹7,355 before tax. If 18% applies, ₹8,678.90. This uses current listed rates, not a guaranteed future bill.

Single is technically enough and can be the cheapest hosting choice on a long term, but lacks the bundled domain. Premium is my practical recommendation for an uncomplicated business-domain launch. Unlimited annual costs ₹1,200 more before tax than Premium annual and adds useful delivery/backup features. Choose it when those benefits matter; Cloud, VPS and Agency would mainly buy unused capacity here.

10. Launch issues found in the project

  • Decide the exact domain spelling. The site consistently says CUTSWAY; custway.com reverses the s/t order.
  • Replace the old https://cutsway.co/ URLs in canonical metadata, Open Graph, JSON-LD, robots.txt and sitemap.xml after the domain is chosen.
  • Create the real business mailbox and update hello@cutsway.co in site settings, static fallback links and structured data.
  • Set the booking URL and social links; the booking URL is currently blank.
  • The current _headers file targets Netlify/Cloudflare. Hostinger needs equivalent server/CDN settings for caching and headers. Configure a branded 404 and HTTPS/www redirects for the selected domain.
  • Verify the external jsDelivr libraries, Google Fonts, mobile rendering, email/booking actions and social preview on the deployed site. Keep the original source backup.
  • This website currently has no client file-upload portal. A request for a raw-video upload service would change the architecture and storage needs.

11. Purchase terms and investigation limits

Hostinger’s refund policy distinguishes eligible hosting’s general 30-day window from special domain rules. New domain registrations have a conditional 96-hour refund window; domain renewals are non-refundable, and a claimed free domain can reduce a hosting refund. Read the exact current policy before relying on a refund. “Cancel anytime” should not be read as a promise of prorated refunds for all unused months.
